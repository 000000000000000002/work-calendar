# 上班日历 · 工时统计

一个纯静态的上班打卡日历：记录每天状态（上班 / 出差 / 请假 / 调休 / 法定休假 / 休息）、加班时长与工作备注，自动统计出勤率、加班天数并按「月薪 ÷ 应出勤天数 × 实际出勤天数」估算工资。

- **在线使用**：`https://<你的用户名>.github.io/work-calendar/`（GitHub Pages 部署）
- **零依赖**：无框架、无后端、无任何网络请求
- **数据私有**：所有记录只保存在使用者本机浏览器的 localStorage 里，作者无法查看

## 文件结构

```
├── index.html    主程序：页面 + 样式 + 全部逻辑（日常无需改动）
├── holidays.js   ★ 法定节假日数据（每年唯一需要更新的文件）
└── README.md     本说明
```

## 功能速览

| 功能 | 说明 |
|---|---|
| 月视图 / 年视图 | 顶部切换；格子上的标签直接显示当天状态 |
| 状态填写 | 右侧面板点选；「加班」可与其他状态同时勾选，并记录加班小时数 |
| 法定节假日 | 放假日自动标红、显示节日名；调休补班日自动标蓝 |
| 动态统计 | 「应出勤工作日」只统计到今天为止的天数，出勤率更真实 |
| 工资估算 | 工具栏填入月薪后，按公式自动计算（仅月视图显示） |
| 悬停全览 | 鼠标悬停任意格子，浮出当天完整信息（含备注全文） |
| 备份恢复 | 「导出备份」生成 JSON 文件；换设备 / 清缓存后用「导入备份」恢复 |
| 清空数据 | 双重确认后删除本机全部记录 |

## ★ 年度更新指南（holidays.js）

**这是每年唯一要改的文件。** 全程在 GitHub 网页上完成，约 5 分钟，不需要装任何软件。

### 什么时候更新

每年 **10~11 月**，国务院办公厅会发布《关于XXXX年部分节假日安排的通知》。看到通知后更新一次，即可让新一年日历正确显示假期。

### 数据从哪来

- 中国政府网 www.gov.cn 搜索「节假日安排」；
- 或国务院客户端 / 新闻报道中的官方通知全文。

**一律以官方文件为准。** 网上流传的「放假预测」不要填。

### 更新步骤（GitHub 网页版）

1. 打开本项目的 GitHub 仓库；
2. 点击文件列表中的 `holidays.js` → 右上角**铅笔图标**（Edit this file）；
3. 按 `Ctrl + F` 搜索「**2027**」（即目标年份），定位到文件底部的注释模板；
4. **解开注释**：删掉模板每一行开头的 `// `；
5. **填入日期**：照官方通知把 `XX` 换成真实日期；
6. 拉到页面底部，点绿色 **Commit changes** 按钮；
7. 等约 30 秒，刷新你的 `github.io` 网址即可看到新一年的假期标注。

> 提示：`'2026': {...}` 后面要跟一个**英文逗号**（模板里 `,` 那行就是干这个的，解注释时注意保留）。

### 数据格式说明

```js
'2027': {
  holidays: [   // 放假区间：起始日 ~ 结束日（含首尾两天）
    { name:'元旦', from:'2027-01-01', to:'2027-01-03' },
    { name:'春节', from:'2027-02-XX', to:'2027-02-XX' }
  ],
  makeupWorkdays: [   // 调休补班日
    '2027-01-XX', '2027-02-XX'
  ]
}
```

| 字段 | 含义 | 填法 |
|---|---|---|
| `name` | 节日名称 | 官方通知里的叫法，如 `'清明节'` |
| `from` / `to` | 放假区间首尾日期 | **含首尾**：放 10/1~10/7 就写 `from:'2027-10-01', to:'2027-10-07'` |
| `makeupWorkdays` | 调休补班日 | 通知里写「X月X日（周六/日）上班」的日期 |

### 常见错误对照表

| 错误写法 | 正确写法 | 说明 |
|---|---|---|
| `'2027-1-1'` | `'2027-01-01'` | 月份、日期必须两位数补零 |
| 区间写成多个单日 | `{ from:'01-01', to:'01-03' }` | 连续放假写成一段区间，不要拆成 3 条 |
| 把「调休放假」的工作日填进补班 | 只填**周末变上班**的日子 | 「X月X日（周五）调休放假」已在 holidays 区间内，不用管 |
| 忘记年份键后面的逗号 | `'2026': {...},` ← 有逗号 | 两条数据之间必须有英文逗号分隔 |
| 引号用了中文引号 `''` | `'元旦'` ← 英文单引号 | 代码里的引号、逗号、冒号全部是英文半角 |

### 改错了会怎样

**程序不会崩溃。** 最坏情况只是某些日期颜色标注不对。发现后改回来再 Commit 一次即可，历史版本随时可以在 GitHub 的 commit 记录里找回。

### 旧年份的数据要删吗

**不用删。** 留着不影响任何功能，翻看往年日历时反而需要它们。

## 隐私说明

- 本页面**不联网、不上传任何数据**：全部记录只存在使用者本机浏览器的 localStorage 中；
- 换浏览器、换设备、清理浏览器数据都会导致记录丢失——请养成「导出备份」的习惯；
- 在公用电脑上使用后，建议点「清空我的数据」。

## 本地运行

无需构建，直接双击 `index.html` 即可在浏览器打开使用（本地数据与线上网址互不相通，属于正常现象）。

仅供个人学习与内部使用。
